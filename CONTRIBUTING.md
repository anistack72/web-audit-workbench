# Contributing

Use Node.js 22 or later. Run `npm test` and `npm run check` before opening a pull request.

Keep changes focused, add a reproducible case for a bug, and document changes to CLI behavior or report schemas. Include your platform and Node version. Tests must use fixtures or a local server, not third-party targets.

Please do not include credentials, customer data, private paths or live vulnerability details in issues, fixtures or examples.
